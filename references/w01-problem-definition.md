## 과정 MVP (P2)
이탈위험고객 대응 상담 시스템. 콜센터 상담사가 통화 중 고객의 이탈 위험 근거와 대응 방안을 빠르게 확인하도록 지원.

## LLM 단독 사용의 한계 (P14)
| 한계 | 뜻 | 해결 방법 |
|---|---|---|
| 정보 단절 | 최신·사내 정보를 모름 | RAG: 정형DB 검색, RAG/GraphRAG, 웹 검색 |
| 실행 불가 | 생각만 하고 행동 못 함 | Tools 연동: API, MCP, Shell/Script |
| 단일 턴 한계 | 한 번 묻고 답하면 끝 | Agentic Workflow: 다단계 작업 수행 |
| 관찰/통제 한계 | 무슨 일이 일어났는지 모름 | Harness: 수행 과정 관찰, 비용·성능·보안 통제 |

- Supervisor가 이상(타임아웃, 비용 초과, 근거 없는 문장)을 감지하고, 중요한 결정은 사람이 검토(HITL)하도록 끼워 넣음

## 하이브리드AI 정의 D·S·R·M (P15)
업무 특성에 맞게 결정론적·비결정론적 처리기를 판단해 쓰고, LLM은 로컬과 클라우드로 나눠 배치하며, 결과를 검증된 하나의 답으로 내놓는 Agentic AI 시스템.

| 구분 | 내용 |
|---|---|
| 하이브리드 데이터 | 정형(컬럼 고정 → RDB), 비정형(문서·이미지 → 벡터DB, 그래프DB) |
| 하이브리드 검색 | 정형검색(NL2SQL), 키워드검색(BM25), 유사도검색(벡터), 관계검색(그래프 + 온톨로지) |
| 하이브리드 역할 | 결정론적(규칙기반 코드, 예측형AI), 비결정론적(생성형AI), Human(되돌릴 수 없는 중요 의사결정) |
| 하이브리드 모델 | 로컬(오픈웨이트), 클라우드(상용 API) |

## 검색·예측·생성의 역할 (P16)
- 검색: 정형/비정형 데이터를 정형·키워드·유사도·관계 검색
- 예측: 과거 데이터 패턴을 학습해 점수/확률 산출
- 생성: 질문 이해, 도구 판단, 답변 문장 생성

## [실습] 유형판별 예시 질문 (P17)
생성·예측·검색·복합 중 판정. 검색이면 정형/유사도/관계 중 어느 유형인지도.
- Q1 이 고객의 최근 3개월 카드 사용액 추이는?
- Q2 이 고객이 앞으로 3개월 안에 카드를 해지할 가능성은?
- Q3 가입 후 6개월 이내 해지하면 연회비는 어떻게 처리되나?
- Q4 이 고객의 주 사용 업종과 연결된 유지 혜택이 있는 카드는?
- Q5 지난 상담기록을 보면 이 고객이 불만을 가진 이유는?
- Q6 VIP 고객에게 보낼 프리미엄 혜택 안내 문구를 정중한 톤으로
- Q7 휴면직전 고객 중 다음 달 휴면전환 위험이 높은 고객은 몇 명?
- Q8 이 고객과 같은 카드를 쓰는 고객들이 최근 많이 옮겨간 카드는?
- Q9 이 고객의 이탈위험과 왜 높은지 상담사가 이해할 수 있게 설명
- Q10 이 고객은 현재 연체 중인가?

## [실습] 상담사 문제정의 (P36)
조별 고객군에 맞게 상담사의 문제를 정의함.

**예시 문제정의**: 콜센터 상담사는 통화 중 고객의 이탈위험 신호를 감지했을 때, 통화를 이어가면서 짧은 시간 안에 고객의 상황과 위험 판단 근거, 안내 가능한 대응 방안을 확인하기 어려워 적절한 상담 기회를 놓치거나 잘못 안내할 수 있습니다.

| 구분 | 예시 내용 |
|---|---|
| 누가 | 하루 약 60콜을 처리하며 여러 화면을 동시에 확인하는 콜센터 상담사 |
| 언제 | 고객의 말에서 이탈위험 신호를 감지했을 때. 예) 카드 사용 감소, 혜택에 대한 불만, 연회비 부담, 해지 또는 다른 카드로의 전환 언급 등 |
| 어디서 | 통화를 이어가며 사용하는 콜센터 상담 화면의 조회창에서 |
| 무엇을 알고 싶은가? | 고객이 실제로 무엇을 불편해하는지, 최근 이용내역과 고객 발언이 일치하는지, 이탈위험을 판단할 근거, 안내 가능한 대응 방안 |
| AI의 답을 받고 무엇을 하는가? | 고객의 의사를 확인하고 상황에 맞는 정보를 안내함. 혜택 신청 등 후속조치는 고객 자격과 고객 동의를 확인한 뒤 진행함 |
| 잘못된 답의 대가 | 위험신호를 놓치면 필요한 상담 기회를 잃을 수 있음. 고객 상황이나 혜택 자격을 잘못 판단하면 부정확한 안내, 민원 또는 잘못된 신청 처리로 이어질 수 있음 |

| 조 | 고객 세그먼트 |
|---|---|
| 1조 | 신규가입 6개월 이내 |
| 2조 | 장기보유고객 |
| 3조 | VIP·고액사용고객 |
| 4조 | 휴면직전고객 |
| 5조 | 다중카드보유고객 |
| 6조 | 연회비부담고객 |

## 합성데이터 (P37)
| 유형 | 데이터 | 내용 |
|---|---|---|
| 정형 | 카드DB | 상품, 연회비, 멤버, 카드, 연체, 회원번호대응표, 가맹점 테이블. 회원번호대응표에 멤버 테이블 가명ID의 진짜 회원번호 |
| 비정형 | 개인회원표준약관 | 장·조·항별 PDF. 머리말, 꼬리말, 페이지번호, 조문번호, 표, 각주 포함 |
| 비정형 | 카드혜택안내 | 카드별 연회비·혜택 PDF. 카드명, 가맹점, 금액, 비율, 실적, 한도, 절차 |
| 비정형 | 상담기록 | 6개 고객군별 가상 상담기록 txt. 메타데이터(상담ID, 날짜, 채널, 회원번호, 공개등급 restricted/internal, 작성일, 소관부서, 버전, 고객명, 전화번호, 이메일, 상담사명, 카드번호, 생년월일, 나이, 상담주제 등) + 본문(고객-상담사 대화) |
